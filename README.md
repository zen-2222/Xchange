# Xchange

Xchange is a front-end website that allows you to quickly exchange currencies using a very fast API.

## Tech Stack

HTML, CSS, JavaScript, TypeScript

## Features

- Extremely fast API response (credits to [@fawazahmed0](https://github.com/fawazahmed0))
- Supports over 330 worldwide Currencies
- Supports Cryptocurrencies
- Responsive

## Challenges & solutions

- Implementing the application logic presented several technical issues, particularly when dealing with incompatible methods and incorrect assumptions about data structures, migrating from vanilla JavaScript to TypeScript helped address these issues by making data structures and expected types explicit, and also exposed potential bugs and inconsistincies I didn't notice at first.
- During development, I considered what would happen if the primary API link I'm using goes down, I addressed this by implementing a fallback mechanism using an alternative API link provided by the same API provider.
